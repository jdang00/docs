The quiz dock holds answer and navigation controls. The **Tools** area holds study aids and live readouts. You can choose what appears in each area.

## Open the customizer

- Desktop: click the sliders button on the quiz dock or beside **Tools** in the module sidebar.
- Phone: open the **More** menu and select **Customize dock**, or open **Tools** and select **Customize tools**.

The customizer previews the desktop and phone layouts before you close it.

## Choose a starting layout

| Preset | Included workflow |
| --- | --- |
| **Essentials** | Check, flag, previous, and next. Less-used actions move to **More**. |
| **Classic** | The standard LearnTerms controls. |
| **Power** | Progress, answer, review, and navigation controls stay within reach. |

Presets change the dock. They keep your current **Tools** selection.

## Use the three zones

| Zone | Use it for | Value |
| --- | --- | --- |
| **Dock** | Frequent answer and navigation actions | Keeps the main study loop one click away. |
| **More menu** | Useful but infrequent actions | Reduces dock width without removing access. |
| **Tools** | Calculator, notes, highlighting, and readouts | Keeps study aids separate from answer controls. |

Drag controls between zones. You can also select a control and use **Move to dock**, **Move to menu**, or **Move to tools**.

## Quick customization

Under **Quick tools**, switch common controls on or off:

- **Notes**
- **Calculator**
- **Reveal answer**
- **Highlight**
- **Streak**
- **Shuffle questions**
- **Progress**
- **Study timer**
- **Next unanswered**
- **Auto next**
- **Text size**
- **Reset**

Open **Fine-tune every button** to access every available control, reorder controls, add dividers, and choose **Icon**, **Text**, or **Both** for dock buttons.

On phones, most dock controls display as icons. **Check** can keep its label. Dividers are hidden. If the dock wraps to two rows, move a control to **More**.

## Available controls

| Group | Controls |
| --- | --- |
| Answer | Check, clear |
| Question | Flag, reveal answer, highlight, notes, calculator, attachments, rationale, edit question |
| Navigate | Previous, next, next unanswered, next flagged, position |
| At a glance | Progress, streak, study timer |
| Session | Shuffle questions, flagged only, unanswered only, reset |
| Preferences | Auto next, shuffle answers, text size, focus mode, settings |
| Layout | Divider |

Some controls appear only when they apply. Examples include **Attachments**, **Rationale**, **Edit question**, and **Focus mode**.

## Saved layout

- Changes appear immediately in the current browser.
- Your layout syncs to your LearnTerms account and follows you to other devices.
- If syncing fails, the layout stays saved on the current device and retries after you reconnect.
- **Reset to default** removes the custom layout and restores **Classic**.

## Why customize it

- Keep frequent controls in a consistent position.
- Move low-frequency actions out of the main study path.
- Put study aids beside the question without crowding answer controls.
- Build a compact phone layout and a fuller desktop layout from the same saved configuration.
