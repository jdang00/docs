---
title: "What progress and mastery mean"
description: "Read completion, correctness, flags, and spaced mastery as different study signals."
---

The module progress overview describes several stages of study. Read them separately so you know what to do next.

| Signal | What it tells you | Next action |
| --- | --- | --- |
| **Unanswered** | No checked answer is recorded for this question. | Try it before revealing the answer. |
| **Incorrect** | The latest checked answer was wrong. | Read the rationale, identify the mistake, and retry later. |
| **Correct** | Your latest checked answer was right. | Return in another run to see whether you can recall it again. |
| **Mastered** | LearnTerms recorded clean recall across two completed module runs at least 30 minutes apart. | Mix it with other material and keep reviewing when useful. |
| **Flagged** | You marked the question for attention. | Revisit it even if your last answer was correct. |

## Completion is coverage of checked questions

Module completion is the share of questions with a checked answer. A checked incorrect answer counts as answered, so a complete module can still have questions that need review. The progress overview shows the counts behind the percentage. If you want to finish an untouched set first, use the unanswered filter; if you want to repair mistakes, inspect incorrect questions and your flags.

This differs from cohort analytics that admins see: those dashboards use *interaction* to describe exposure across students and questions. Your module mastery is a separate measure of repeated recall.

## How mastery builds

Mastery builds automatically from clean first checks in completed module runs. The qualifying runs must be at least 30 minutes apart. Reset the module when you want a fresh run; previous mastery is retained. A retry after seeing feedback can help you learn, but it does not replace a clean first answer in a later run. Revealing the solution before checking also prevents that attempt from serving as clean recall evidence. If a later checked answer is incorrect, the question needs fresh evidence.

Open a question in the progress overview to see why it is not yet mastered. You may see that it has one of two completed runs, that the answer was revealed first, that you retried, or that the question changed. Flags remain reminders and do not change mastery.

## Use each signal for a decision

- **Many unanswered:** finish a first pass through the module.
- **Mostly correct, little mastery:** return later for another clean run instead of repeatedly checking the same answer immediately.
- **Incorrect or flagged cluster:** read the rationales and cited pages, then practice that concept in context.
- **Mastered but uncertain:** keep the flag and test the idea in a mixed set; mastery records prior evidence, not a promise about a future exam.
