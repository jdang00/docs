---
title: "Building an exam-week study plan"
description: "Use module practice, flags, mastery, and custom tests to organize a focused week of review."
---

Start with the exam's actual scope: classes, modules, and any instructor emphasis. LearnTerms can show where you have worked and let you build targeted practice, but you still need to decide which material the exam covers.

## Make a short priority list

For each relevant module, check three things: how many questions you have checked, which questions are incorrect or flagged, and whether you can answer them from memory in a later run. Put unvisited or repeatedly missed concepts ahead of another pass through familiar items. Use the module progress overview for question status; [progress and mastery](/students/understanding-progress-and-mastery) explains what each signal means.

| When | Main task | LearnTerms action |
| --- | --- | --- |
| Early week | Find gaps across the exam scope | Open each module; finish unanswered questions and flag uncertain ones. |
| Middle of week | Repair specific concepts | Read rationales and cited pages; add short private notes and repeat flagged questions. |
| Later week | Check transfer across modules | Build a mixed custom test from the relevant class modules, with shuffled order. |
| Final review | Revisit remaining weak points | Use test **Review** filters and a short module pass; stop adding broad new material unless required. |

Adjust the sequence to the days you actually have. If you have one session, do a small mixed test and spend the remaining time reviewing its errors. If you have more time, let an initial module pass guide the rest of the week.

## Choose the right practice mode

Use **module practice** for free-response explanations, first exposure to a topic, and careful review of rationales. You can reset a completed module for another run; saved mastery evidence carries over. A clean first answer across completed runs at least 30 minutes apart contributes to mastery, so a later pass tests recall more meaningfully than an immediate retry.

Use a **custom test** when you need mixed retrieval or timing practice. The builder lets you select modules, question types, count, source filter, shuffling, time limit, and pass threshold. Its **Flagged only** filter uses your flagged module questions; **Not yet completed** uses questions without a recorded interaction. Free response is excluded from the current custom test builder, so keep a module session for written explanations.

## Convert the test into the next session

After submitting, open **Summary** for the overall result and **Review** for the actual questions. Check **Incorrect**, **Flagged**, and **Unanswered** separately. An unanswered item may indicate pacing or a skipped topic; a flagged correct item may indicate fragile understanding. Write down two or three recurring concepts and pick the next module or small test from them.

Do not treat one score or a full completion bar as proof of exam readiness. A better final check is whether you can answer representative questions, explain the reasoning, and handle them in mixed order.
