---
title: "Private question notes"
description: "Save a private, formatted note with a specific question while you study."
---

Open **Notes** from the module **Tools** area.

## What a note belongs to

- One note belongs to one question and one user.
- Other students, contributors, and admins do not see it.
- The note stays with the question when you leave and return.
- Notes are available only while you have access to the published question's class.

## Write and format

The editor supports:

- bold
- italic
- underline
- bullet lists
- numbered lists
- undo and redo

Each note can contain up to 3,000 characters. Links, images, headings, code blocks, and arbitrary HTML are not stored.

## Saving

Notes save automatically after you stop typing. The footer shows **Saving**, **Saved**, **Unsaved changes**, or **Not saved**.

If saving fails, your current text stays in the editor. Use **Retry save** after reconnecting.

LearnTerms also keeps a local recovery draft for unsaved changes. If the same note changes in another tab or device, choose:

- **Use saved version** to load the newer server copy.
- **Keep my version** to save the current draft over it.

## Panel behavior

- Notes open in the right-side panel.
- Opening the calculator closes Notes because only one side panel can be open at a time.
- Desktop restores the last open side panel after a reload.
- Phones start with the side panel closed so it does not cover the question.

## Why use notes

- Record why a distractor was tempting.
- Save a mnemonic or distinction beside the exact question that prompted it.
- Write a short correction in your own words after reading the rationale.
- Preserve reasoning that a flag alone cannot explain.

Keep notes short and question-specific. Use another system for full lecture notes.
