---
title: "Choosing the right question type"
description: "Match the skill you want to assess to a question format students can answer and you can grade fairly."
---

Choose the format after you write the learning objective. Start with a sentence such as “The student can distinguish two mechanisms using one finding.” Then decide what evidence of that skill you need from the student's answer.

| If the student must... | Consider... | Check before publishing |
| --- | --- | --- |
| Choose among plausible alternatives | **Multiple choice** | Each distractor tests a real misconception; the stem supports one defensible answer or answer set. |
| Recall a short, specific term or value | **Fill in the blank** | The accepted answer covers valid spelling, terminology, or units as appropriate. |
| Connect several related pairs | **Matching** | Each pair has a clear relationship; answer choices do not reveal every pair by elimination alone. |
| Explain, interpret, or justify in their own words | **Free response** | The prompt names the required points and the rationale supports fair grading. |
| Judge one precise statement | **True/false**, where available | The statement has a stable truth value and avoids hidden qualifiers. |

## Use the answer to choose the format

Imagine the objective is to recognize why finding A favors explanation X over explanation Y. A multiple choice item can ask the student to select X from plausible alternatives. A free-response item can ask them to name X **and identify the finding that distinguishes it from Y**. Those answers provide different evidence: selection shows discrimination; explanation shows whether the student can state the reasoning.

Use fill in the blank when the exact answer itself matters. If several clinically equivalent phrases should count, define those accepted answers clearly or use free response. Matching works when every pair matters. If one relationship is the real objective, a short individual question often gives clearer feedback than a long matching set.

## Account for the study surface

Free response is available in module practice and uses **Submit** for feedback. The current custom test builder offers multiple choice, fill in the blank, and matching; it excludes free response. If a concept must appear in a custom test, include an appropriate supported format in addition to any free-response practice.

Writing effort also matters. A free-response prompt should earn that effort by testing reasoning or recall that options would give away. Ask for one decision with a stated number of reasons, rather than several unrelated explanations in one response. See [Writing free-response questions](/contributors/writing-free-response-questions).

## Check the finished item

1. Cover the options or answer key. Can you state exactly what the stem asks?
2. Answer it using only the presented case, source material, and expected module knowledge.
3. Read the rationale. Does it explain the specific skill in the objective?
4. Try the learner view. Confirm the answer control and feedback suit the format.

If the best answer depends on interpreting a case, [write the case around that decision](/contributors/writing-clinical-case-questions). If multiple formats work, prefer the one that yields useful feedback with the least unnecessary work for the student.
