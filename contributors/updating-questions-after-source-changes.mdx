---
title: "Keeping questions current when course material changes"
description: "Recheck published questions, answers, rationales, and citations after a source or curriculum update."
---

When a lecture, protocol, or source document changes, find the questions that depend on the changed claim. A page citation helps locate evidence, but it does not guarantee that the answer is still current.

## Identify the affected questions

1. Record the changed topic, old statement, new statement, and the source page or section that now supports it.
2. Open the relevant class and module in the curation page. Search for the key terms in stems, options, and rationales.
3. Include questions generated from the source, manually cited questions, and questions that teach the same concept without a citation.
4. Check related modules if the concept appears in more than one place.

Do this review when content changes meaning, not only when a file is renamed or reuploaded. A replacement file can have different page numbers, so verify the *actual page content* before retaining a citation.

## Decide what each question needs

| Finding | Action |
| --- | --- |
| The teaching point is still correct; only wording changed | Update terminology and the rationale if it helps clarity. |
| The answer or a distractor is now wrong | Revise the stem, options, correct answer, and rationale together. |
| The cited page no longer supports the answer | Select the new supporting page, or remove the citation until you can verify one. |
| The question depends on a retired rule | Move it to **Draft** while revising, or **Archive** it if it should leave the active bank. |
| The new source permits two reasonable answers | Clarify the stem or recognize both valid routes in a free-response rationale. |

Use [Manual source citations](/contributors/manual-source-citations) to edit pages or change documents. Keep citations narrow enough that future reviewers can find the support quickly.

## Recheck the learner experience

Answer the revised question in learner mode. Confirm the correct answer, rationale, feedback, media, and citation tell the same story. For free response, retest an ordinary paraphrase and any newly valid alternative. See [Handling alternate valid answers](/contributors/alternate-valid-answers).

LearnTerms tracks study evidence against question content; changing the stem, answer structure, or free-response ground truth can require students to build fresh mastery evidence. Treat that as a reason to make a coherent edit and verify it, rather than splitting one correction across several partial edits. A source citation update alone is not a substitute for reviewing the question content.
