## What the Content Library is

The **Content Library** is the cohort-scoped source workspace for Question Studio. It stores the original PDF, extracted text and layout, search index, and reusable topic map for each document.

The library is cohort-scoped. Staff see documents for their own cohort; developers can work across cohorts when their role permits it.

## Upload a document

Open **Admin → Content Library** and click **Add file**. Drag a file into the uploader or browse for it.

Current upload limits are:

- PDF only
- up to `30 MB`
- up to `150` pages

The upload progress bar covers the transfer to storage. After that finishes, background processing continues through extraction, indexing, and topic mapping. You can leave the page after the job is queued.

<Note>
Long or image-heavy PDFs can take several minutes. After upload, the document continues processing before topic-based generation becomes available.
</Note>

## Understand document readiness

Each document moves through four stages:

1. **Stored** — the original PDF is saved.
2. **Extracted** — text, tables, layout, and page boundaries are prepared.
3. **Indexed** — the extracted material is searchable by the generation system.
4. **Mapped** — the document is organized into reusable topics.

Cards and list rows show live processing status. A green check means all four stages are complete. Open **Properties** for the full stage-by-stage view or to resume a failed job.

See [Content processing pipeline](/admin/content-processing-pipeline) for status details and recovery steps.

## Find a document

The toolbar supports:

- **Search files** by title, description, or original file name
- sorting by **Recently updated**, **Name (A–Z)**, **Oldest first**, **Largest first**, or **File type**
- **Grid** and **List** views

Grid cards emphasize file readiness and visual scanning. List view adds explicit page, size, and updated columns.

## Open the document drawer

Select a document to open its detail drawer. Expand it to fullscreen when you need more room.

<Tabs>
  <Tab title="Preview">
    Shows the extracted Markdown that Question Studio can read. LearnTerms renders headings, tables, and math; wide tables can open fullscreen. Use **View as slide deck** to render slide-like source as a presentation, or switch back to notes.

    The preview can be clipped for speed. Preview length and indexed-source completeness are separate states.
  </Tab>
  <Tab title="Source">
    Shows the original stored PDF. Use this view to compare the extraction with the actual page layout. The original page image helps you verify the document, but Question Studio relies on extracted text for generation.
  </Tab>
  <Tab title="Properties">
    Shows processing stages, file metadata, timestamps, extraction details, index identifiers, and storage metadata. If processing needs attention, use **Resume processing** after reviewing the displayed error.
  </Tab>
</Tabs>

## Manage a document

From the card or drawer you can:

- **Rename** the library title without changing the original file
- **Open** the original PDF in a new tab
- **Remove** the document after confirming the destructive action

Use descriptive titles and remove duplicates. Clear naming makes source selection much easier in Question Studio.

## Check quality before generation

Before using a document:

1. Wait for the processing status you need.
2. Compare **Preview** with **Source** on representative pages.
3. Check tables, equations, headings, and any image-heavy sections.
4. If essential visual facts are missing from extracted text, narrow the run to readable pages or replace the PDF with a cleaner export.
5. Use topic mode only after **Mapped** is complete; otherwise use page mode.

## Common problems

### The upload button stays disabled

Confirm the file is a PDF, no larger than `30 MB`, and your account belongs to a cohort with staff access.

### The document is still processing

Open **Properties** to identify the active stage. The job continues in the background, so refreshing or leaving the page is unnecessary.

### Preview is empty or incomplete

Compare it with **Source**. Image-only scans and complex slide exports often provide too little extractable text for reliable questions.

### The document is missing from Question Studio

Confirm it belongs to the same cohort and has completed extraction and indexing. Topic mode additionally requires mapping.

### Topic mapping failed

Open **Properties** for the error and resume processing. You can still use **Pages** if readable extracted pages and the search index are available.
