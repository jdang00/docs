title: "Source context"
description: "Choose the pages or mapped topics Question Studio may read and keep each run focused."
---

**Context** is the extracted source material Question Studio may use for a run. Focused context usually produces sharper questions, so select only the material needed for the requested run.

## Choose Pages or Topics

### Pages

Use **Pages** for direct control.

- Open **Choose your pages**.
- Select page circles or use **Select all**.
- Enter ranges such as `1–12, 24, 38–45` and click **Add pages**.
- Turn on **Selected only** to audit the final set.
- Click a thumbnail to preview it; use the page circle as the separate selection control.

The preview can switch between the original PDF page and **Text used for questions**. The extracted text is what the generation system can reliably use.

### Topics

Use **Topics** after the document reaches the **Mapped** stage.

- Search topic titles, summaries, and key terms.
- Select **All**, **None**, or individual topics.
- Open topic details to review page references, objectives, and suggested question types.

Pages shared by several topics count once in the source scope.

## Read the context guidance

Question Studio reports how many pages the agent will read. In the page picker, the context meter also shows a suggested band and warns when a selection is broad enough to risk shallow questions.

Use the meter as selection guidance. Quality still depends on source clarity, topic fit, and review. Slide pages, textbook pages, and OCR-heavy scans can contain very different amounts of usable text.

For a focused run:

1. Start with the smallest section that contains the needed evidence.
2. Match the requested question count to the number of distinct concepts.
3. Split unrelated chapters or lecture sections into separate runs.
4. Add pages only when a question truly needs them.

## What happens when the source changes

Question Studio ties a page selection to the indexed version of the document. If the source is reprocessed while you are selecting pages or generating questions, the app clears or rejects the stale selection. Reload the pages and start a new run so citations continue to match the source.

## When Topics is unavailable

While topic mapping is incomplete, Question Studio offers **pages you choose**. Completed extraction and indexing can still support a page-based run.

Open the document's **Properties** panel in Content Library to check whether mapping is queued, active, complete, or failed.

## Final source check

Before saving a candidate, verify:

- the cited page is in your selected scope
- the quoted evidence supports the correct answer
- every factual claim in the rationale is supported
- visual details required by the question are present in extracted text
