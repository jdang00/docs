## What the admin dashboard is

The dashboard at `/admin` is the starting point for cohort staff. It combines three workflow shortcuts with semester-aware class management.

The primary shortcuts are:

- **Content Library** — upload and prepare source documents
- **Question Studio** — generate and review source-grounded draft questions
- **Class Progress** — explore cohort participation, curriculum coverage, students, and generation runs

The dashboard itself is a routing and maintenance surface. Detailed analytics live in **Class Progress**.

## Who can access it

Admin routes require an authenticated LearnTerms user with a staff role:

- `curator`
- `admin`
- `dev`

Backend authorization binds the dashboard and its linked workspaces to the user's permitted cohort, regardless of URL or client-side changes.

## Manage classes by semester

The **My Classes** section filters classes by the selected semester. LearnTerms remembers the last semester name you used when possible.

From this section, authorized users can:

- open a class
- edit class metadata
- add a class
- switch into **Reorder Mode** and drag classes into a new order
- delete a class after reviewing its module and question counts

Class order is saved to the backend and persists across sessions.

## Quick Links

Admins and developers can open **Quick Links** to manage cohort shortcuts. Keep links focused on resources students actually need, and use clear labels so the dashboard remains easy to scan.

## Delete classes carefully

Deleting a class affects the content hierarchy beneath it. Before confirmation, LearnTerms loads the class's module and question counts so you can judge the impact.

<Warning>
Use deletion only for a class that should be removed permanently. Confirm the semester and class identity, then review the displayed content counts before proceeding.
</Warning>

## Recommended admin sequence

1. Select the correct semester.
2. Confirm classes and their order.
3. Add or update modules inside the destination class.
4. Prepare sources in **Content Library**.
5. Generate and save drafts in **Question Studio**.
6. Publish only after module-level review.
7. Use **Class Progress** to see whether students are reaching the new material.
